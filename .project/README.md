# .project

Operational context for the project, generated by AgentReady.

- `docs/CONSTITUTION.md` — purpose, constraints, and fundamental rules.
- `docs/STACK.md` — technologies, dependencies, and operational commands.
- `docs/PRINCIPLES.md` — development principles and conventions.
- `adr/` — reconstructed architectural decisions and their log.
- `gates/` — quality checks that changes must respect.

Decisions marked as *inferred* are hypotheses reconstructed from evidence:
they should be validated with the team.
